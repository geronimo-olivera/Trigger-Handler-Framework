# Documentation

Index of project documentation. Keep each doc focused and link it here as it's added.

## Structure

- `architecture/` — design decisions, data model notes, integration diagrams
- `guides/` — setup, deployment, and how-to guides for contributors
- `runbooks/` — operational procedures (deployments, rollbacks, incident handling)

Create subfolders as needed — don't add them speculatively before there's content for them.
